## DSH 是什么

Harness 直译马具：套在大模型外面让它真正干活的一层——组织提示词、给工具、执行操作、记录每一步、需要时请人确认；Claude Code、Codex 同属此类。[claimed] 拆机 01 §01（分类表述，机制见下文本地核实部分）

DSH = DeepSeek 开源的 Agent Harness（命令行名 dsh），2026-08 开源、MIT、开发者预览；交付形态 web/CLI/桌面/SDK，模型不限 DeepSeek。[claimed] 拆机 01 §01（时间与许可证未在本地核实）

## 核心包速查（ctx 键）

`core/session`→`ctx.sessions`（追加式 SessionEvent 日志+内存存储）；`core/system-prompt`→`ctx.systemPrompt`（提示词片段+工具 schema 组装）；`core/tools`→`ctx.tools`（作用域化注册表+带把关执行流水线）；`core/agent`→`ctx.agents`（Agent 接口+注册表+`agent/*` 事件）；`core/agent-loop`→`ctx.agentLoop`（默认驱动器）；`core/scope`（库，无 ctx 键）；`llm/llm`→`ctx.llm`（消息/流式词汇+适配器 seam）。[verified] docs/architecture.zh.md:55-67

## 一句话旅程（轮次流程）

一步 = 一次模型请求 + 它调用的工具；一轮 = 零或多步，领取首条输入前打开、不再欠工作时关闭。[verified] docs/architecture.zh.md:85

心智模型：模型不执行任何东西，只产出 tool calling 指令格式；宿主代码识别该格式、调用对应工具、把结果作为上下文回传给模型——想和做是分离的。[verified] docs/architecture.zh.md:85

核心圈：turn/start → 领取输入 → 组装提示词+工具 schema → step/start → 流式请求 → tool/call*（pre-execute→execute→post-execute）→ step/end → 有欠债或新输入则下一步 → turn/end；完整事件流见 docs/architecture.zh.md:85 起的流程块。[verified]

两个边界：轮次是“零或多步”——首个领取的输入被拒或为空时，轮次不含任何步骤就关闭；一步可带多个工具调用（流程里 tool/call* 是复数）。[verified] docs/architecture.zh.md:85

事件三域：会话事件 = 追加到日志的持久事实（重载后仍在）；agent/* 事件 = 观察/拦截进行中的工作；能力事件 = 向 seam（fs/*、tools/*、telemetry/*）附加策略与适配器。[verified] docs/architecture.zh.md:69-75
